# Fact Check Manager

Fact Check Manager is a tool for the explicit comparison of two editions as a "before" and "after", allowing any 
application the ability to offer content teams a means to show the differences between the old and new version of a
given document.

The goal of Fact Check Manager is to simplify this as much as possible for the end user while allowing the software team
the ability to tie it into their application via a ready to use API and Signon support.
